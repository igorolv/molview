# Строение молекул: валентные углы и гибридизация

Программа строит трёхмерную модель молекулы по её формуле и показывает
валентные углы и гибридизацию центральных атомов. Геометрия **вычисляется**
по теории отталкивания электронных пар валентной оболочки (ОЭПВО, теория
Гиллеспи), а не берётся из готовой таблицы координат.

Работает целиком в браузере, без интернета и без установки.

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка автономной версии — один HTML-файл, который открывается двойным
щелчком с флешки:

```bash
npm run build
```

Результат: `dist/index.html` (около 135 КБ, всё внутри — код, справочник
элементов и база молекул).

## Проверка

```bash
npm test
```

Прогоняет два набора проверок:

* `scripts/selftest.ts` — вся база (89 молекул): разбор, построение,
  длины связей, отсутствие наложений атомов, сравнение предсказанных
  валентных углов с экспериментальными, контроль формы и гибридизации
  для 27 эталонных молекул;
* `scripts/smilestest.ts` — 25 молекул, которых в базе нет (аспирин,
  кофеин, адамантан, антрацен, гептафторид иода), плюс проверка сообщений
  об ошибках ввода.

## Что можно вводить

| Ввод | Пример | Что произойдёт |
|---|---|---|
| Брутто-формула | `C2H6O` | покажет **все** изомеры из базы |
| Название по-русски | `бензол` | найдёт по названию или синониму |
| SMILES | `CC(=O)Oc1ccccc1C(=O)O` | построит молекулу, которой нет в базе |

## Устройство

```
src/
  data/elements.json    справочник элементов: радиусы, ЭО, валентные электроны, цвета
  data/molecules.json   база молекул — ТОЛЬКО связность (SMILES) и справочные данные

  chem/                 химическое ядро, не зависит ни от браузера, ни от библиотек
    vec.ts              векторная алгебра, повороты, метод Якоби
    periodic.ts         таблица элементов, длины связей, неявные водороды
    smiles.ts           разбор SMILES в граф молекулы
    resonance.ts        усреднение кратностей равноценных связей (делокализация)
    vsepr.ts            ТЕОРИЯ ГИЛЛЕСПИ: неподелённые пары, геометрия, гибридизация
    rings.ts            поиск наименьших циклов (SSSR)
    build3d.ts          построение трёхмерных координат
    analyze.ts          сборка полного разбора молекулы
    formula.ts          брутто-формулы, разбор запроса-формулы
    database.ts         загрузка базы, поиск, изомеры

  render/renderer.ts    собственный трёхмерный рендер на Canvas 2D
  ui/app.ts             интерфейс: поиск, каталог, панель разбора
```

Каталог `chem/` намеренно не содержит ни одного обращения к браузеру —
при переносе программы на C++ или Python переписывается только `render/`
и `ui/`.

## Ключевая идея

Расположение электронных групп вокруг атома не берётся из таблицы, а
находится как минимум энергии их взаимного отталкивания на сфере:

```
E = Σ (wᵢ · wⱼ) / rᵢⱼ⁶
```

где `w` — «размер» электронной группы: неподелённая пара крупнее
связывающей, кратная связь крупнее одинарной. Из одной этой минимизации
получаются все правила учебника — тетраэдр, плоский треугольник,
сжатие углов неподелёнными парами, экваториальное положение пары в
тригональной бипирамиде (SF₄, ClF₃, XeF₂) и транс-положение двух пар
в октаэдре (XeF₄ — плоский квадрат).

Подробности — в пояснительной записке `docs/`.

## Точность

Средняя ошибка предсказания валентного угла в области применимости
модели — **1,7°** (66 сравнений со справочными данными).

Отдельно вынесены случаи, где расхождение закономерно и объясняется
теорией: элементы 3-го периода и ниже (H₂S — 92,1° вместо 104,5°),
угловое напряжение малых циклов (циклопропан — 60° вместо 109,5°),
тонкие искажения в гипервалентных частицах. Программа помечает такие
атомы предупреждением и поясняет причину.
